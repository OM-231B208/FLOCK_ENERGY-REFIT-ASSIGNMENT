# Notebooks

The reproducible analysis is maintained in `src/` and run with `python src\run_analysis.py`.

The earlier root-level exploratory notebook has been moved to `notebooks/archive/` for local reference only. Its saved outputs predate the current scripts and may be stale; the archive is excluded from Git so those cached results are not mistaken for current findings. Use the scripts and regenerate the figures and CSV outputs for the authoritative analysis.
